NOMAAD Бизнесүүд — гарын авлага

Систем хэрхэн ажилладаг, өдөр, сар, жил бүр юу хийх, асуудал гарвал яах вэ. Хиймэл оюун ухааны тусламжгүйгээр ажиллуулахад зориулав.

Санхүүгийн бичилт хэрхэн үүсдэг вэ? Борлуулалт, зарлага, бараа орлого, цалин, кассын баримт бүрээс журнал автоматаар тооцоологдоно. Тиймээс нягтлан гараар давхар бичих шаардлагагүй, нэг ч борлуулалт санхүүгээс алдагдахгүй. Хянах самбарын «Санхүүд бичигдсэн эсэх шалгалт» үүнийг өдөр бүр шалгадаг.

2. Өдөр бүр (ажилтан)

  1. Дэлгүүрийн хуудсаа нээж нэвтрэх нэр, кодоороо орно.
  2. Борлуулалт: бараагаа сагсанд нэмж, төлбөрийн хэлбэрийг (Бэлэн / Карт / Шилжүүлэг / Зээлээр) сонгоод «Төлбөр авах». И-баримт автоматаар гарна.
  3. Зээлээр өгвөл хэнд өгснийг (нэр, утас) заавал бичнэ — авлага болж бүртгэгдэнэ.
  4. Зарлага: кассаас мөнгө гаргавал төрлийг нь сонгоод дүнгээ бичнэ.
  5. Өдрийн төгсгөлд «Өдрийн касс хаах» — кассанд байгаа бэлэн мөнгийг тоолж оруулна. Зөрүү санхүүд автоматаар орно.
  6. Буруу баримт гаргасан бол тухайн өдөрт нь «Баримт буцаах».
Интернэт тасарсан ч борлуулалт компьютер дээр хадгалагдаад, интернэт орж ирмэгц өөрөө илгээгдэнэ. Гэхдээ хөтчийн түүх, кэшийг (cache) бүү цэвэрлээрэй.

4. Сар бүр

  1. Санхүү → Хянах самбар: «Энэ сар» сонгоод бүх шалгалт ногоон эсэхийг харна.
  2. Бараа материал → Тооллого: бодит үлдэгдлээ тоолж оруулна.
  3. Санхүү → Касс, харилцах: кассын болон банкны дансны үлдэгдлийг банкны хуулгатай тулгана. Зөрвөл журналын бичилтээр засна.
  4. «Бүх тайлан» → Excel татаж нягтлан руу явуулна.
  5. Он хаах, нөөц хуудсанд «Сүүлийн нөөц хуулбар» 7 хоногоос хуучин биш эсэхийг харна.

5. Жил бүр — он хаах (1-р сарын эхний 7 хоногт)

Google Sheet ойролцоогоор 500,000 мөр хүртэл хурдан ажилладаг. Он хааснаар өмнөх оны мөрүүд архив руу шилжиж, үндсэн Sheet үргэлж зөвхөн тухайн оны мэдээлэлтэй, хурдан хэвээр үлдэнэ.

  1. Бүх дэлгүүрийн 12-р сарын 31-ний бичлэг илгээгдсэн эсэхийг шалгана (компьютерууд интернэттэй).
  2. Компани бүрийн Санхүү → Хянах самбар (Энэ он) шалгалт ногоон байх ёстой.
  3. Санхүү → Дансны удирдлага → Он хаах, нөөц → «20XX оныг хаах». Оныг бичиж баталгаажуулна.
  4. Систем: (а) тайлангуудыг Excel-ээр татна, (б) Sheet-ийг «NOMAAD архив 20XX» нэрээр бүтэн хуулна, (в) тэр оны мөрүүдийг хасна, (г) оны эцсийн үлдэгдлийг шинэ оны 1-р сарын 1-нд «Он нээлт» болгож оруулна.
  5. Өмнөх оны дэлгэрэнгүйг харах бол архив файлыг эсвэл татсан Excel-ийг нээнэ.
Он хаасны дараа тэр оны огноотой бичлэг хоцорч ирвэл тайланд орохгүй — хянах самбар анхааруулна. Тэр дүнг «Журналын бичилт»-ээр гараар оруулна.

6. Нөөц ба сэргээх

  • Долоо хоног бүрийн Даваа гарагт 03:00-д Sheet бүтнээрээ Google Drive-ийн «NOMAAD Бизнесүүд — нөөц» хавтаст автоматаар хуулагдана. Сүүлийн 12 хуулбар хадгалагдана (хуучин нь хогийн саванд 30 хоног байна).
  • Том өөрчлөлтийн өмнө «Он хаах, нөөц» хуудсаас «Одоо нөөц авах».
  • Архив («NOMAAD архив 20XX») хэзээ ч автоматаар устахгүй.

Сэргээх

  1. Sheet-ийн өөрчлөлтийг буцаах бол эхлээд Sheet → Файл → Хувилбарын түүх (Version history)-ээс сэргээж болно.
  2. Бүхэлд нь сэргээх бол нөөц хуулбарын хуудаснуудыг үндсэн Sheet рүү хуулна. Үндсэн Sheet-ийн нэр, хаягийг солихгүй байх нь чухал (системд түүний ID бичигдсэн).
Google бүртгэлдээ 2 шаттай баталгаажуулалт заавал асаагаарай — бүх мэдээлэл тэр бүртгэлд байгаа.

7. И-баримт, принтер

  • Махны болон Аяллын дэлгүүр хоёулаа Вайс бротерсийн ТТД-ээр (салбар 001, 002) баримт гаргадаг. Нэг Windows компьютер дээрх PosAPI хоёуланд нь хангалттай.
  • Тухайн компьютер асаалттай, PosAPI ажиллаж байх ёстой. Дэлгүүрийн хуудасны «И-баримт» тохиргоонд «Холболт шалгах».
  • PosAPI баримтаа 3 хоногт нэг удаа заавал нэгдсэн системд илгээх ёстой (интернэттэй үед автоматаар). Тохиргооны «Одоо илгээх» товчоор гараар ч болно.
  • Принтер: 80 мм дулааны касс принтерийг USB-ээр залгаж, Windows-д үндсэн принтер болгоно. Хөтчийн хэвлэх тохиргоонд цаас 80 мм, захын зай «Байхгүй».
  • Сугалааны дугаар, QR кодыг зөвхөн хэвлэнэ — системд хадгалагддаггүй.

9. Аюулгүй байдал

  • Удирдлагын нэвтрэх нэр, кодыг зөвхөн эздүүд мэднэ. Анхны «admin» эрхийн кодыг бодит ашиглалтын өмнө заавал солино, хоёр дахь эзнийг «Эзэн» эрхээр нэмнэ.
  • Ажилтан гарахад түүнийг «Үгүй» (идэвхгүй) болгоно.
  • Google Sheet-ийг бусадтай хуваалцахгүй («Хуваалцах» тохиргоо зөвхөн өөрт).
  • Өртөг үнэ зөвхөн Google Sheet-д хадгалагддаг — нийтэд нээлттэй GitHub кодонд байхгүй.

10. Хөгжүүлэгчид (өөр хүн засварлах бол)

  • Код: GitHub — akunaaanujin-blip/nomaad_catering, business/ хавтас. GitHub Pages-ээр нийтлэгддэг (push хийхэд 1-2 минутад шинэчлэгдэнэ).
  • Сервер: business/google_apps_script.js = Apps Script төслийн код. Засаад script.google.com дээр хуулж → Deploy → Manage deployments → Edit → Version: New version → Deploy. Холбоос (URL) өөрчлөгдөхгүй.
  • Кодын ADMIN_PIN = '0000' бол зөвхөн загвар; жинхэнэ кодыг Apps Script дээр л бичнэ (GitHub-д хэзээ ч бичихгүй).
  • Алдаа гарвал Manage deployments → Edit → Version-оос өмнөх хувилбарыг сонгоод Deploy — шууд буцна.
  • Нөөцийн автомат ажлыг шинээр тохируулах бол Apps Script редактороос installBackup функцийг нэг удаа ажиллуулна.
  • Sheet-ийн бүтэц: Бүртгэл (борлуулалт/зарлага/касс хаалт), Бараа, Ажилтан, Цалин, Үлдэгдэл (барааны хөдөлгөөн), Журнал (гар бичилт, кассын баримт, он нээлт), Харилцагч. Баганын толгойг солихгүй.
  • Санхүүгийн дүрэм: business/reports.js — дансны төлөвлөгөө, автомат журнал, хөдөлгөөнт дундаж өртөг, тайлангууд.

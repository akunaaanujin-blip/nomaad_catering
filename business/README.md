# NOMAAD Бизнесүүд

3 бизнесийн ажилтны хуудас + удирдагчийн нэгдсэн самбар.

| Хуудас | Хэн ашиглах |
|---|---|
| `meat.html` | 🥩 Махны дэлгүүрийн ажилтан |
| `cozy.html` | 🏠 Cozy Home Ulaanbaatar-ын ажилтан |
| `travel.html` | 🎒 NOMAAD аяллын дэлгүүрийн ажилтан |
| `admin.html` | 📊 Удирдагч (2 хүн, PIN кодтой) |
| `index.html` | Хуудас сонгох цэс |

## Ажилтны хуудас: 3 товч
- **＋ Борлуулалт**: бараа сонгох, тоо, үнэ, төлбөр (бэлэн/карт/шилжүүлэг)
- **− Зарлага**: төрөл, дүн, тайлбар
- **🔒 Өдрийн касс хаах**: касст байгаа бэлэн мөнгийг тоолж оруулахад зөрүүг автоматаар гаргана

Интернэт тасарсан үед бичлэг утсанд хадгалагдаж, интернэт орохоор автоматаар илгээгдэнэ.

## Удирдлагын самбар
Өнөөдөр / өчигдөр / 7 хоног / сар / 30 хоногоор: бизнес бүрийн орлого (бэлэн, карт, шилжүүлэг), зарлага, цэвэр ашиг, хамгийн их зарагдсан бараа, касс хаалтын зөрүү, бүх бичлэг.

## Тохируулах (нэг удаа)
1. Google Drive дээр шинэ Google Sheet үүсгэнэ (жишээ нь "NOMAAD Бизнесүүд").
2. **Extensions → Apps Script** цэсийг нээгээд `google_apps_script.js`-ийн кодыг бүхэлд нь хуулна.
3. Кодын дээд хэсэгт байгаа `ADMIN_PIN = '0000'`-ийг өөрийн PIN кодоор сольно.
4. **Deploy → New deployment → Web app**, *Execute as: Me*, *Who has access: Anyone* гэж тохируулна.
5. Гарсан `https://script.google.com/macros/s/.../exec` холбоосыг `config.js`-ийн `API_URL = ''` хэсэгт тавина.

Sheet дотор 2 хуудас автоматаар үүснэ:
- **Бүртгэл**: бүх борлуулалт, зарлага, касс хаалт
- **Бараа**: бизнес бүрийн барааны жагсаалт, үнэ. Эндээс бараа нэмэх эсвэл үнэ солиход ажилтны хуудсанд автоматаар гарч ирнэ.

`API_URL` хоосон байхад хуудсууд **туршилтын горим**-оор ажиллана: мэдээлэл зөвхөн тухайн төхөөрөмжид хадгалагдана, удирдагчийн PIN нь `0000`.
